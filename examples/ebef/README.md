# EBEF reference facility

This package exercises Lab's SBOLInventory ingestion against a public-data model shaped around Caltech's [Ecology and Biosphere Engineering Facility](https://resnick.caltech.edu/resource-centers/ecology-and-biosphere-engineering-facility-ebef).

The catalog was generated by `sbol-inventory`'s `ebef_catalog` example at sbol-rs revision `42806cdb708e2265f19aab668cf177c68f019846`, using SBOLInventory Profile 0.2 artifacts from revision `371c919c763c970091a12a6449099b5591deb3ec`. It contains one facility, 12 zones, 28 assets, and 30 capability offerings.

This is an architectural example, not an operational source of truth. It omits serial numbers, private layout, network details, booking state, calibration records, and execution claims. Public equipment facts remain `Described` with `UnspecifiedControl`, so Lab must not treat this catalog as permission or configuration to operate EBEF hardware.

Run `lab check examples/ebef` from the repository root to compile the portable package and validate the inventory. The omitted `facility` selector is intentional because the document contains exactly one `fac:Facility`.
